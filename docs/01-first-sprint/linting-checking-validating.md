## Learning Objectives

By the end of this section, you will be able to:

- Run a linter and fix the issues it reports.
- Explain what 'Definition of Done' means in agile.
- Use automated checks as a quality gate.

## Introduction

Professional software teams maintain code quality through automated checks. Linters, type checkers, and formatters form a safety net that catches problems before code review.
