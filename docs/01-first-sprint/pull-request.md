**Topics:** Creating pull requests, Code review, Approving and merging

## Learning Objectives

By the end of this section, you will be able to:

- Open a pull request on GitHub.
- Provide constructive code review feedback.
- Merge a pull request after approval.

## Introduction

Pull requests are how professional developers share and review code. They create a structured conversation around proposed changes, ensuring quality before code is merged.
