**Topics:** Project boards, User stories, Acceptance criteria

## Learning Objectives

By the end of this section, you will be able to:

- Read and interpret a user story.
- Define clear, testable acceptance criteria.
- Set up a project board to track work.

## Introduction

Before your first day, you'll be given a work sample task. This mirrors a common hiring practice—and teaches you about user stories and acceptance criteria, the foundation of agile planning.
