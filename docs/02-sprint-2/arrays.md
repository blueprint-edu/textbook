**Topics:** Arrays, Higher-order array methods, map, filter, reduce

## Learning Objectives

By the end of this section, you will be able to:

- Use map, filter, and reduce to transform arrays.
- Render lists of data in React components.
- Write tests for components that render arrays.

## Introduction

Arrays are everywhere in software. Higher-order array methods like map and filter are concise, composable, and expressive—essential tools in any TypeScript developer's toolkit.
