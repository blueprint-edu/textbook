## Learning Objectives

By the end of this section, you will be able to:

- Create and switch between Git branches.
- Merge a feature branch into main.
- Resolve a small merge conflict.

## Introduction

Branches let multiple developers work on different features simultaneously without interfering with each other. They're the backbone of collaborative software development.
