**Topics:** Sprint review, Sprint retrospective, Sprint planning

## Learning Objectives

By the end of this section, you will be able to:

- Present completed work in a sprint review.
- Identify process improvements in a retrospective.
- Plan the next sprint using a prioritized backlog.

## Introduction

The end of a sprint is a moment for reflection and planning. The sprint review shows what was built; the retrospective examines how the team worked together.
