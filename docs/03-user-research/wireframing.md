**Topics:** Wireframes, Lo-fi prototyping, Design iteration

## Learning Objectives

By the end of this section, you will be able to:

- Create a low-fidelity wireframe for a user interface.
- Use wireframes to communicate design intent.
- Iterate on a design based on feedback.

## Introduction

Wireframes are rough sketches of an interface. They help teams align on layout and flow before investing time in code.
