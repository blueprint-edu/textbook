**Topics:** References vs. copies, Deep copies, Testing equality

## Learning Objectives

By the end of this section, you will be able to:

- Distinguish between reference equality and value equality.
- Create deep copies of objects.
- Write tests that verify data independence.

## Introduction

JavaScript objects are passed by reference, not by value. Understanding this distinction is essential for writing correct stateful code in React.
