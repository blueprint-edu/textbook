## Learning Objectives

By the end of this section, you will be able to:

- Interpret a code coverage report.
- Identify untested branches and add tests to cover them.
- Explain why 100% coverage is not the sole goal.

## Introduction

Code coverage measures how much of your code is exercised by tests. It's a useful signal, but coverage alone doesn't guarantee correct behavior.
