**Topics:** Nested state objects, Immutable updates, useState with objects

## Learning Objectives

By the end of this section, you will be able to:

- Update nested objects in useState correctly.
- Avoid direct state mutation.
- Use spread syntax to create updated copies.

## Introduction

When state contains nested objects, updating it requires care. Mutating state directly causes subtle bugs—React requires immutable updates.
