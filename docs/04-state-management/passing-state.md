**Topics:** Lifting state, Prop drilling, Shared state

## Learning Objectives

By the end of this section, you will be able to:

- Lift state up to a common ancestor.
- Pass state and state-update functions as props.
- Identify when prop drilling becomes a problem.

## Introduction

When multiple components need access to the same data, state is 'lifted' to their closest common ancestor. This section explores the pattern and its tradeoffs.
