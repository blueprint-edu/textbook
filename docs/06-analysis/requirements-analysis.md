**Topics:** Functional requirements, Non-functional requirements, Requirements traceability

## Learning Objectives

By the end of this section, you will be able to:

- Distinguish functional from non-functional requirements.
- Prioritize requirements using the MoSCoW method.
- Trace requirements to implementation decisions.

## Introduction

Requirements analysis transforms user needs into specific, testable criteria. Good requirements are the foundation of software that actually serves users.
