## Learning Objectives

By the end of this section, you will be able to:

- Apply Nielsen's ten usability heuristics to a UI.
- Identify common accessibility failures.
- Propose improvements grounded in usability principles.

## Introduction

Usability principles give us a shared vocabulary for evaluating interfaces. Nielsen's heuristics remain the most widely cited set of practical UI guidelines.
