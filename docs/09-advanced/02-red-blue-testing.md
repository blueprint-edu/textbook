## Learning Objectives

By the end of this section, you will be able to:

- Explain the red/blue team model.
- Identify attack vectors in a web application.
- Apply a security-first mindset to code review.

## Introduction

Red/blue testing applies adversarial thinking to software quality. Red teams attack; blue teams defend. Together, they surface vulnerabilities before real attackers do.
