Blueprint aims to meet **WCAG 2.2 Level AA** for all textbook content and interactive examples.

## Our Commitments

- Sufficient color contrast in both light and dark themes (minimum 4.5:1 for text).
- Full keyboard navigation for all interactive elements.
- Visible focus indicators.
- Descriptive labels for all controls and embedded playgrounds.
- No information conveyed by color alone.
- Reduced-motion support.
- Responsive text without clipping at 200% zoom.
- Proper heading hierarchy.
- Alt text on all images.
- Skip-to-content link.
- Screen-reader announcements for example execution status.

## Known Limitations

Interactive playground content is rendered inside iframes by LiveCodes. Accessibility within iframe content is subject to LiveCodes' own accessibility implementation.

## Reporting Accessibility Issues

If you encounter an accessibility barrier, please open an issue using the "Technical Defect" template and include "accessibility" in the title.
